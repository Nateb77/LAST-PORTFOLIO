Project Case Study

Financial Goals Tracker

A responsive budgeting web app that helps users track savings goals, explore spending progress, and visualize account performance with clean, accessible charts.

Project details

  • Languages used: HTML, CSS, JavaScript
  • Created: March 2026
  • Role: Front-end developer, UI design
  • Link: Live demo

Overview

This project includes an interactive savings dashboard with a progress meter, category cards, and goal-setting controls. The page design focuses on clarity by organizing financial metrics into meaningful groups and applying consistent spacing.

Highlights

  • Responsive layout adapted for mobile and desktop screens
  • Clear visual hierarchy for important balances and goals
  • Accessible color contrast and readable typography
